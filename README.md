# 🗓️ Zion Patch Window Planner

Plan patch windows against SLAs, change freezes and business calendars — automatically. Part of the **Zion ITOps AI Suite (Batch 72)**.

## What it does
- Computes optimal patch windows per system based on SLA, criticality and usage patterns
- Respects change freezes, blackout dates and dependency graphs
- Generates change-request drafts with rollback plans
- Simulates patch risk using historical failure data

## Key features
- Calendar heatmap of safe windows across the estate
- Conflict detection with incidents from [Zion Incident Triage](https://github.com/Zion-support/zion-incident-triage)
- Post-patch verification checklists; failures feed [Zion Incident Postmortem Writer](https://github.com/Zion-support/zion-incident-postmortem-writer)
- ServiceNow/Jira change integrations
